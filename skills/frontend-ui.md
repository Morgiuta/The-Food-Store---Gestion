# skills/frontend-ui.md

## Alcance

Usar este skill cuando el cambio afecte al frontend React.

## Reglas

- Respetar la estructura modular existente.
- No mezclar lógica de API dentro de componentes visuales.
- Usar services/hooks cuando corresponda.
- Mantener estilos consistentes.
- No duplicar componentes si ya existe uno reutilizable.
